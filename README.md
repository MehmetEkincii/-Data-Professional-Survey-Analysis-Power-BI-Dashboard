# -Data-Professional-Survey-Analysis-Power-BI-Dashboard
This Power BI project analyses global survey responses from data professionals to uncover trends in salaries, skills, job satisfaction, and career challenges.

Project Overview:
This project visualizes insights from a real-world survey of data professionals across multiple countries and job roles. Using Power BI, I transformed raw survey data into an interactive dashboard that reveals patterns in compensation, programming language preferences, work-life balance, and the barriers to entering the data field.
The analysis answers key questions like: 
Which data roles earn the most?
What programming languages dominate? 
How satisfied are data professionals with their work-life balance and salaries?

Business Questions Answered:
What is the average salary across different data roles?
Which countries have the highest participation in the data profession?
What are the most popular programming languages among data professionals?
How difficult is it to break into the data industry?
How satisfied are data professionals with their work-life balance and compensation?
What is the demographic profile (average age) of survey respondents?

What Was Done:
Data Cleaning & Transformation (Power Query)
Cleaned and standardized raw survey responses to ensure consistency
Removed incomplete or invalid entries
Transformed salary data from text ranges into numeric values for analysis
Standardized country names and job titles across responses
Created calculated columns for aggregated metrics


Dashboard Design & Visualizations
Built a comprehensive single-page dashboard featuring:
KPI Cards:

Count of Survey Takers: 630 respondents tracked
Average Age: 29.87 years across all participants

Visualizations:

Treemap — Survey participation by country (Canada, India, United States, United Kingdom)
Stacked Bar Chart — Average salary by job title, segmented by role (Data Scientist, Data Engineer, Data Architect, Data Analyst, Database Developer, Student/Looking)
Stacked Column Chart — Favorite programming languages by job title, showing distribution across Python, R, C/C++, JavaScript, and Java
Donut Chart — Difficulty to break into data (categorized as Very Easy, Easy, Difficult, Neither easy nor difficult, Very Difficult)
Gauge Charts — Satisfaction metrics:

Work/Life Balance Happiness: 5.74/10
Salary Happiness: 4.27/10



Design Choices:
Teal color scheme with professional dark header
Clean, uncluttered layout that guides the viewer through demographic → salary → skills → satisfaction
Consistent visual hierarchy across all charts
Clear labeling and legends for self-explanatory insights

Key Insights:
Data Scientists lead in compensation — Data Scientists earn the highest average salary, followed by Data Engineers and Data Architects
Python dominates — Python is overwhelmingly the most popular programming language across all data roles, with over 400 votes
North America and Asia drive participation — The majority of survey respondents came from Canada, India, the United States, and the United Kingdom
Breaking in is challenging — 42.7% of respondents found it "Neither easy nor difficult" to break into data, while 24.76% found it "Difficult"
Moderate satisfaction levels — Work-life balance scores higher (5.74/10) than salary satisfaction (4.27/10), indicating compensation is a pain point
Young workforce — The average age of data professionals surveyed is under 30, reflecting a relatively early-career demographic

[PowerBI dashboard.webp](https://github.com/MehmetEkincii/-Data-Professional-Survey-Analysis-Power-BI-Dashboard/blob/main/PowerBI%20dashboard.webp)
A single-page interactive dashboard designed with strategic visual flow — starting with demographics (country treemap, survey count), moving through compensation and skills analysis (salary by role, programming languages), and ending with satisfaction metrics (work/life balance and salary gauges)

Design highlights:
Teal and earth-tone color palette for professional, approachable visualization
Cross-filtering enabled — click any chart element to dynamically update all visuals
Left-to-right narrative flow guides viewers from "who" (demographics) → "what" (compensation/skills) → "how satisfied" (gauges)
Strategic chart selection — treemaps for geographic distribution, stacked bars for salary comparison, donut chart for difficulty perception, and ranges for satisfaction scores on a 0-10 scale

The layout balances analytical depth with visual simplicity, making complex survey data digestible in under 30 seconds while supporting deeper exploration through interactivity.
